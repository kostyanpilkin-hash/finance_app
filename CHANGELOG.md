## 2026-11-07

- Левое меню с иконками по разделам (общие, оформление, курсы, telegram, устройства, безопасность, резервные копии, о программе) вместо единого длинного списка.

### Операции: дневные карточки, календарь и отмена удаления
- Список сгруппирован в карточки по дням («Сегодня/Вчера/дата») с итогом дня справа; строки без рамок, действия иконками при наведении.
- Страница открывается на «сегодня»; навигатор ‹ дата › и выпадающий календарь с точками на днях с операциями (новая команда `transaction_days`); поиск ищет по всей истории.
- Редактирование раскрывается прямо под выбранной строкой (форма вынесена в `TxForm`).
- Удаление — мгновенное, со снэкбаром «Операция удалена · Отменить» (восстановление через `entity_restore`); добавлен лёгкий toast-механизм на zustand.

### Дашборд: периоды и анимированные диаграммы
- Переключатель периода «Неделя / Месяц / 30 дней» — применяется к KPI и всем диаграммам.
- Четыре диаграммы: расходы и доходы по категориям и по людям. Своя SVG-кольцевая `DonutChart`: градиентные сектора с разделителями и процентами, при наведении сегмент выдвигается и увеличивается, остальные блекнут; одинаковые цвета сегментов автоматически перекрашиваются из палитры.
- Видимость трёх дополнительных диаграмм настраивается в «Настройки → Общие».
- В легенде — иконки категорий и кружки с инициалами людей; все суммы конвертируются в валюту отображения (`useDisplayMoney`).

### Счета в виде банковских карт
- Карточки-счета: градиент цвета счёта, чип, значок бесконтактной оплаты, банк, `•••• 1234`, владелец и логотип платёжной системы (Visa/Mastercard/Белкарт/Мир/UnionPay); у наличных и сбережений свои стили. Архив — сворачиваемый блок, сверху — итог по валютам.
- Миграция v3: `accounts.bank`, `accounts.payment_system` с валидацией; живое превью карты в форме редактирования; компактный вариант карточек на дашборде.

### Аналитика
- KPI с дельтой к прошлому периоду (расходы, доходы, итог, средний расход в день, прогноз на конец месяца), тренд по 6 месяцам, накопительная линия баланса, график по дням, блоки «по людям» и «по счетам».
- Исправлено сложение сумм в разных валютах: всё считается в валюте отображения.

### Напоминания и цели
- Кнопка «Внести» в блоке «Нужно оплатить» открывает предзаполненную форму операции (вид, сумма, счёт, категория, комментарий); после сохранения напоминание отмечается оплаченным и `next_due` сдвигается.
- Миграция v4: у цели появился привязанный счёт (`goals.account_id`) — прогресс считается по балансу счёта автоматически; кнопка «Отложить» создаёт перевод на счёт цели.

### Журнал, загрузка и бандл
- Журнал: чипы-фильтры по сущностям и человекочитаемые изменения «было → стало» — суммы с валютой, даты, имена связанных записей (счета, категории, люди), цвета свотчами, переведённые имена полей.
- Скелетоны загрузки на дашборде, в операциях, счетах и аналитике.
- `useEnsureRates`: валюты без загруженных курсов НБРБ подтягиваются лениво — «нет курса для части счетов» самоисчезает.
- Страницы переведены на `React.lazy`: стартовый JS-бандл 891 → 381 КБ (recharts грузится только с аналитикой).

## 0.1.4 — 2026-11-05

### Онбординг: присоединение к существующему хосту
- Новый шаг «Как будет работать это устройство?» после выбора языка: «Новая база — это устройство хост» или «Присоединиться к хосту». Раньше свежая установка всегда создавала локальных пользователей, которые после подключения к хосту дублировались с притянутыми.
- Шаг присоединения: авто-поиск хостов в локальной сети (mDNS) или ввод адреса вручную → код сопряжения → имя устройства. Команда `join_host` подключается, вытягивает весь журнал синхронизации за один вызов и отмечает онбординг завершённым; после успеха приложение перезапускается уже в режиме клиента (mode хранится в БД и читается один раз при открытии — до перезапуска процесс остаётся «хостом»).
- Устройство сразу привязывается к нужному пользователю: `/pair` возвращает `userId` из кода сопряжения — он сохраняется как `current_user_id`, лишних «вторых Марий» больше нет.
- В «Настройки → Устройства» после подключения добавлена подсказка о необходимости перезапуска.

### Разблокировка базы ключом восстановления
- Если файл БД существует, а ключ из системного хранилища потерян (переустановка ОС, новое устройство, перенос бэкапа), приложение больше не падает при старте: показывается экран «База зашифрована» с полем ввода ключа. Ключ сначала проверяется открытием БД и только потом записывается в keyring — неверный ключ не «отравит» хранилище. После принятия приложение перезапускается открытым.
- Реализован задуманный ранее `open_with_recovery` путь (команды `db_status`, `unlock_db`; `Db::open` без правильного ключа даёт `need_recovery_input` → `db_locked`).

## 0.1.1 — 2026-11-04

### Курс НБРБ на дату операции
- Подсказка конвертации «≈ … по курсу НБРБ» теперь считается по курсу на дату операции, а не на сегодня: при вводе расхода/дохода задним числом и бот, и форма в приложении подставляют исторический курс.
- Хранилище: новый `convert_minor_at` выбирает курс не позже даты операции (`date <= ?`, ближайший более ранний — для выходных и праздников); для даты без записи курс лениво скачивается с НБРБ (`?ondate=`) и сохраняется через журналируемый `rate_upsert`. Будущие даты и ошибки сети не блокируют ввод — берётся последний известный курс или кнопка подсказки скрывается.
- Новая команда `convert_at` для фронта: форма операции запрашивает конвертацию на дату из поля даты.
- Автообновление курсов теперь всегда тянет и RUB (раньше — только USD/EUR).

### Бот: операции за конкретную дату
- В разделе «🧾 Операции» новая кнопка «📅 По дате»: выбор Сегодня / Вчера / Завтра или ручной ввод ДД.ММ (и ДД.ММ.ГГГГ). Список показывает операции только за выбранный день с теми же просмотром, изменением и удалением; кнопка «✖️ Все даты» снимает фильтр. Дату можно и нажать кнопкой, и просто написать сообщением.
- Фильтр сохраняется при возврате из просмотра и редактирования операции и сбрасывается при новом открытии раздела из меню.

### Дашборд: исправления расчётов
- Общий баланс снова учитывает BYN-счета: курс BYN принимался за 1 вместо 1 000 000 в масштабированных единицах, поэтому сумма в BYN делилась на миллион и исчезала из итога.
- «Расходы/доходы за месяц» подтягиваются: колонка суммы получила явный алиас `amount` — раньше фронт читал ключ `sum(t.amountMinor)`, а SQLite возвращал `SUM(t.amountMinor)` в другом регистре, и значение терялось.
- Круговая диаграмма складывает расходы в валюте общего баланса (курсы НБРБ), а не смешивает копейки разных валют; при наведении показывается сумма с валютой, а не сырое значение.

### Валюта при вводе дохода и расхода
- Новый шаг мастера бота «💱 Валюта» после выбора счёта: валюта счёта первой кнопкой, затем BYN/USD/EUR/RUB. Если валюта отличается от валюты счёта, бот спрашивает сумму по счёту и предлагает её по курсу НБРБ одной кнопкой.
- Миграция v2: в операциях хранится введённая сумма и её валюта (`orig_amount_minor`, `orig_currency`); баланс считается по сумме в валюте счёта. Проверка в `transaction_upsert`: только для доходов и расходов, валюта отличается от валюты счёта, сумма > 0.
- То же в форме операции в приложении: выбор валюты рядом с суммой, поле «Сумма по счёту» с подсказкой по курсу; в списке операций исходная сумма показывается в скобках.

### Telegram-бот: новый интерфейс и функции
- Исправлено «молчание» `/menu`: команды и текст больше не правят старую карточку где-то выше в истории — старая карточка гасится, новая присылается внизу чата. Ошибки бота пишутся в `<appdata>/logs/bot.log` (без токена), раньше они терялись молча.
- Постоянные кнопки внизу экрана (Расход, Доход, Балансы, Меню) и список команд Telegram (`setMyCommands`).
- Главное меню с обращением по имени и мини-дашбордом: общий баланс, расходы/доходы за сегодня и месяц в валюте общего баланса.
- Оформление: суммы `1 234,50 BYN`, цветные эмодзи (🔴 расход, 🟢 доход, 🔵 перевод), даты «Сегодня, 4 ноября», прогресс-бар шагов мастера, эмодзи на всех кнопках.
- Мастер: шаг времени операции («Сейчас» или ЧЧ:ММ), частые категории со звёздочкой первыми, кнопка «Сохранить сразу» после выбора даты; после сохранения карточка остаётся итогом, новое меню присылается отдельно.
- Новые разделы: балансы всех счетов с пересчётом, курсы НБРБ с обновлением, цели с прогресс-баром (пополнить, снять, сумма цели, название, архив), последние операции обоих пользователей с просмотром, изменением и удалением (автор, источник, время создания и изменения; всё пишется в журнал).
- Сводка за сегодня, вчера, неделю и месяц: итоги, сравнение с прошлым периодом, топ расходов и круговая диаграмма (PNG рисуется локально).

### Этап 4 — Telegram-бот (часть 1)
- Токен бота хранится в системном хранилище ОС (keyring); настройка в «Настройки → Telegram-бот».
- Привязка: 6-значный код (10 минут) по пользователю; бот связывает чат с пользователем.
- Пошаговый ввод кнопками: вид (расход/доход/перевод) → сумма → счёт → категория; перевод между валютами спрашивает зачисляемую сумму; комментарий последним шагом.
- Сводки /today /week /month, /balance, /undo (последняя запись бота за 10 минут).
- Запасной формат одной строкой: «-500 продукты молоко», «+1000 зп» — бот попросит только счёт и категорию.
- Ответы бота на языке пользователя (ru/be/en).

### Этап 2/3 — аналитика и курсы (продолжение)
- Аналитика: периоды день/неделя (с пн)/месяц/произвольный, столбики расходов и доходов по дням, итог и сравнение с прошлым периодом в процентах.
- Курсы НБРБ: автоматическое обновление раз в сутки (фоновый планировщик), кнопка «Обновить курсы» и список курсов в настройках.
- Фото чеков: миниатюры в списке операций.

### Этап 2 — UI (продолжение)
- Дашборд: общий баланс в BYN по последним курсам, круговая диаграмма расходов по категориям за месяц (recharts).
- Операции: фильтры по счёту и категории, группировка списка по дням, прикрепление фото чека (файлы в `attachments/`, показ через asset protocol).
- Команда `rates_refresh`: обновление курсов НБРБ для всех валют счетов + USD/EUR.

### Этап 1/2 — базовый интерфейс
- Дашборд: расходы/доходы за месяц по валютам, плитки счетов с балансом.
- Операции: список с поиском по комментарию, добавление/редактирование расхода, дохода и перевода (с ручной суммой зачисления для разных валют), удаление.
- Счета: создание и редактирование (тип, последние 4 цифры, валюта, владелец, цвет, «в общий баланс»), архив и восстановление.
- Категории: вкладки расходы/доходы, создание/редактирование (имя, иконка, цвет), удаление с переносом операций в другую категорию.
- Журнал: лента изменений «было → стало» по полям, восстановление удалённых записей.
- Переводы ru/be/en для всех новых строк и базовых категорий.

### Этап 1 — ядро данных (часть 1)
- `crates/storage`: SQLCipher-база (файл шифруется целиком, ключ в хранилище ОС), миграции, все таблицы из плана (счета, категории, операции, вложения, цели, напоминания, курсы, audit_log, outbox/conflicts, telegram-*).
- Единая точка записи `apply_change()`: версии, seq на хосте, очередь на клиенте, подробный журнал изменений «было → стало» по каждому полю.
- Репозитории: пользователи, счета (карта с 4 цифрами, наличные, сбережения), категории (базовый набор, удаление с переносом в «Прочее»), операции (расход, доход, перевод между валютами с ручной суммой зачисления), вложения, цели, журнал с фильтрами, восстановление удалённого.
- Балансы по счетам и общий баланс с пересчётом в выбранную валюту по курсу НБРБ; клиент api.nbrb.by (BYN/USD/EUR/…).
- Ключ восстановления: base32-формат, показывается в мастере первого запуска.
- Мастер первого запуска: язык → пользователи → стартовые счета → ключ восстановления.
- Тесты: деньги, периоды (неделя с пн, границы месяцев), балансы и переводы, журнал, перенос категорий, шифрование (без ключа файл не читается).
- Примечание: для сборки SQLCipher на Windows нужен Perl — используется портативный Strawberry Perl в `tools\strawberry-perl` (без админских прав).

### Этап 0 — каркас проекта
- Cargo workspace: `crates/core` (деньги и валюты с тестами), заготовки `crates/storage`, `crates/api`, `crates/bot`, десктоп-оболочка `src-tauri` на Tauri 2.
- Интерфейс: React 19 + TypeScript + Tailwind 4, боковое меню со всеми разделами (пока заглушки), горячие клавиши Ctrl/Cmd+1…9.
- Темы оформления из TutorApp (28 шт.) плюс фирменная «Изумруд» по умолчанию; языки: русский, беларуский, английский.
- Трей (открыть/выход, локализуется), закрытие окна сворачивает в трей, защита от второго запуска, автозапуск со стартом в трей.
- Иконка «зелёный кошелёк» (`scripts/generate-icon.py`).
- Установщики Windows: MSI (язык ru-RU — иначе WiX не принимает кириллическое имя «Финансы») и NSIS (русский/английский).
- GitHub Actions: проверки на каждый push (Windows) и сборка релизов Windows + macOS universal с публикацией в `finance_app_public`.
